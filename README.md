# 📚 Story Reader — Android App

A calm AI narrator that reads your PDF/TXT books aloud.
Plays in background even when screen is off.

## Download APK
1. Go to the **Actions** tab on GitHub
2. Click the latest green ✅ build
3. Scroll down to **Artifacts**
4. Download **story-reader-apk**
5. Extract the zip → install the .apk on your phone

## Features
- 📖 Open any PDF or TXT book
- 🎙️ Calm narrator voice (device TTS)
- 📱 Background playback (screen off)
- ⏮⏭ Crash-free Next / Previous
- 💾 Auto-saves your reading position
- ⚡ Speed control slider
